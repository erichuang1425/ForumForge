# Support

ForumForge is a pre-release, maintainer-led open-source project. Support is
best-effort; clear reproductions and sanitized fixtures receive priority.

| Need | Channel |
| --- | --- |
| Reproducible bug | Use the GitHub bug-report form |
| Support for a forum | Use the forum-support form |
| Focused product idea | Use the feature-request form |
| Setup or contributor question | Use the question form |
| Vulnerability | Follow [SECURITY.md](SECURITY.md); do not open a public issue |

Before opening an issue:

1. Search existing issues and [ROADMAP.md](ROADMAP.md).
2. Run the current source build when practical.
3. Remove private notes, cookies, tokens, authentic post content, and personal
   data from screenshots, logs, and fixtures.
4. Include the browser version, ForumForge commit/version, public page type, and
   exact steps.

The maintainer aims to triage normal issues within seven days, but this is a
target rather than a service-level agreement. Security reports use the response
targets in [SECURITY.md](SECURITY.md).
